# Unum IDE — Landing page

Sitio web de Unum IDE, construido con React, Vite y Tailwind CSS. El código del IDE está en [sebashuesca/Unum](https://github.com/sebashuesca/Unum); este repositorio contiene únicamente la web.

## Desarrollo

```bash
npm install
npm run dev
```

## Despliegue en Vercel

Importa `sebashuesca/unum-dev` en Vercel. El proyecto usa el preset de Vite: comando de build `npm run build` y directorio de salida `dist`. No necesita variables de entorno ni rutas especiales.
